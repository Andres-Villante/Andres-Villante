**Stack:** React, Tailwind CSS, Node.js, Firebase y Cloud Functions.

🔗 [Repositorio](https://github.com/Andres-Villante/mi-gestion-contable)

#### 🎮 Atado con Alambre — Publicado

Videojuego de física para Android y web, centrado en la construcción de torres mediante una grúa. Incluye diferentes modos de juego, rankings, personalización y compras integradas.

**Stack:** JavaScript, Matter.js, Capacitor y Firebase.

🔗 [Google Play](https://play.google.com/store/apps/details?id=com.atadoconalambre.torre) | [Sitio web](https://valkyrgames.com/atado-con-alambre/)

#### 🧩 Fit Into Place — En desarrollo

Videojuego de puzzles 3D centrado en el ensamblaje de piezas mecánicas.

**Stack:** JavaScript, Three.js, Capacitor y Playwright.

🔗 [Sitio web](https://valkyrgames.com/fitintoplace/)
